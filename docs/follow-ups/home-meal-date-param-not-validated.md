# 존재하지 않는 날짜를 주소에 쓰면 다른 날로 보임

**Symptom**: `/?d=2026-13-45`처럼 형식만 맞고 존재하지 않는 날짜를 주소에 쓰면 오류 없이 열리지만 넘친 다른 날(예: 2월 14일)로 보인다.

**Observed evidence**: 2026-11-19, 브라우저에서 `/?d=2026-13-45`를 열면 "2월 14일 일요일"이 보였다. 정규식(`^\d{4}-\d{2}-\d{2}$`)만 확인하고 달력상 날짜인지는 확인하지 않는다. `app/(tabs)/page.tsx`, `app/(sub)/upload/page.tsx`, 서버 액션 입력 확인에 같은 정규식이 있다.

**Suspected cause**: 날짜 검증이 형식에서 멈춘다. 화면 안의 링크로는 만들어지지 않고 주소를 손으로 고칠 때만 생긴다.

**What was tried**: 스펙 밖의 엣지케이스라 고치지 않았다.

**Proposed next step**: `lib/date.ts`에 달력상 유효한 날짜인지 확인하는 함수를 두고 세 곳의 정규식을 바꾼다.
